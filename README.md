# Corporate Financial Health Analytics

An end-to-end financial analytics project using Power BI and Excel to analyze corporate financial performance, profitability, balance sheets, and key financial ratios.

---

## What's in This Project

* Historical corporate financial statement datasets
* Balance sheet and income statement analysis
* Interactive Power BI dashboard
* Executive-level financial KPIs and performance metrics
* Profitability, financial position, and ratio analysis
* Visual insights to support data-driven financial decisions

## Dataset Overview

| File                          | Description                                                             |
| ----------------------------- | ----------------------------------------------------------------------- |
| `balanceSheetHistory.xlsx`    | Historical assets, liabilities, equity, and other balance sheet metrics |
| `incomeStatementHistory.xlsx` | Historical revenue, expenses, profits, and income statement metrics     |

The datasets provide the financial information required to evaluate corporate performance over time.

* Evaluate historical financial performance

## How to Run

**Power BI Dashboard:**

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download or clone this repository.
3. Open the `.pbix` dashboard file in Power BI Desktop.
4. If prompted, reconnect the data sources to the Excel files.
5. Refresh the data and explore the dashboard.

**Data Files:**

1. Locate the Excel files in the `Data/` folder.
2. Ensure the source paths in Power BI point to the correct files.
3. Refresh the dataset to load the available financial data.
